# 🪚 Симулятор Звука Бензопилы

Веб-интерфейс для математической модели звука бензопилы с настройкой всех параметров в реальном времени.

## Особенности

- **Все параметры на виду**: Каждый параметр отображается с текущим значением и единицами измерения
- **Реальное время**: Звук генерируется и воспроизводится в реальном времени, без сохранения в файл
- **Интерактивный дроссель**: Ползунок газа для управления оборотами двигателя
- **Группировка параметров**: Все параметры разделены на логические группы:
  - 🔥 Двигатель и Сгорание
  - ⛽ Топливо и Смесь
  - ⚙️ Механика и Зазоры
  - 🔗 Цепь и Резка
  - 🔊 Акустика и Среда

## Установка и Запуск

```bash
# Установите зависимости (если не установлены)
pip install flask numpy scipy

# Запустите сервер
python server.py
```

Сервер запустится на порту 5000. Откройте в браузере:
```
http://localhost:5000
```

## Использование

1. Нажмите **"▶ Запустить"** для начала воспроизведения звука
2. Используйте **ползунок "Педаль газа"** для изменения оборотов двигателя
3. Настраивайте параметры в любых группах - изменения применяются мгновенно
4. Наблюдайте за текущими значениями RPM и позиции дросселя
5. Нажмите **"⏹ Стоп"** для остановки воспроизведения
6. Нажмите **"↺ Сброс"** для возврата всех параметров к значениям по умолчанию

## API Эндпоинты

- `GET /` - Веб-интерфейс
- `GET /api/params` - Получить все параметры
- `POST /api/update_param` - Обновить параметр
- `POST /api/throttle` - Установить позицию дросселя
- `GET /api/rpm` - Получить текущие обороты
- `GET /api/audio_stream` - Поток аудио данных
- `POST /api/reset_params` - Сбросить параметры

## Технологии

- **Audio**: NumPy, SciPy
- **Frontend**: HTML5, CSS3, JavaScript (Web Audio API)
